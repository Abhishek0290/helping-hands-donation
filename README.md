# 🤝 HelpingHands Donation

A community-driven donation platform designed to connect donors with meaningful causes and support initiatives.

Live Demo:
https://abhishek0290.github.io/helping-hands-donation/

---

## 🚀 Features

- Donation-focused platform
- Clean and responsive interface
- QR-based donation support
- Thank-you page flow
- Mobile-friendly design
- Deployed using GitHub Pages

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

---

## 📌 Project Overview

HelpingHands Donation was built to simplify the donation process and make it easier for people to contribute towards meaningful social causes through a clean and accessible web platform.

---

## 🌟 Goal

To create a simple, user-friendly and accessible donation platform that encourages community participation and social impact.
